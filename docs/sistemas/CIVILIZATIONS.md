## 📝 Estructura JSON de Civilización

```json
{
    "civilizationId": "string",
    "name": "Nombre Visible",
    "description": "Descripción larga",
    "icon": "ruta/al/icono.png",
    "color": "#hexcolor",
    
    "bonuses": {
        "buildSpeed": 1.25,
        "unitSpeed": 1.15,
        "startingResources": {
            "wood": 50,
            "food": 0,
            "gold": 0,
            "stone": 0
        }
    },
    
    "uniqueUnit": {
        "id": "unitId",
        "name": "Nombre Unidad",
        "baseUnit": "warrior|archer|villager",
        "bonuses": {
            "attackDamage": 1.3,
            "maxHp": 1.2
        }
    },
    
    "unitOverrides": {
        "villager": { "name": "Nombre Custom" },
        "warrior": { "name": "Nombre Custom", "attack": 12 }
    },
    
    "buildingOverrides": {
        "house": { "name": "Nombre Custom" }
    },
    
    "technologyOverrides": {
        "techId": { "name": "Nombre Custom" }
    },
    
    "uniqueTechnologies": [
        {
            "id": "techId",
            "name": "Nombre Tecnología",
            "cost": { "food": 300, "gold": 200 },
            "effects": { ... }
        }
    ]
}
```

## 🎮 Cómo Agregar una Civilización

1. **Crear archivo JSON** en `assets/civilization/`:
```json
{
    "civilizationId": "myNewCiv",
    "name": "Mi Nueva Civilización",
    "description": "Descripción...",
    "icon": "assets/icons/civs/mynewciv.png",
    "color": "#ff5500",
    "bonuses": { ... }
}
```

2. **Agregar icono** en `assets/icons/civs/`

3. **Reiniciar el juego** - El dataLoader la detectará automáticamente

## 💻 Código Relacionado

| Componente | Archivo |
|------------|---------|
| Carga de civilizaciones | `dataLoader.js` |
| Aplicar bonificaciones | `civilizationManager` |
| Selección de civilización | `main.js` → `populateCivilizations()` |
| Display de colores | `Entity.js` → `getTeamColor()` |

### Obtener Civilización en Código

```javascript
// Obtener todas las civilizaciones
const civs = dataLoader.getAllCivilizations();

// Obtener civilización específica
const romans = dataLoader.getCivilization('romans');

// Aplicar bonificaciones a unidad
civilizationManager.applyUnitBonuses(unit, 'romans');

// Obtener color de equipo
const color = civilizationManager.getTeamColor('vikings', 'player');
```

## 🎯 Estrategias por Civilización

### Mongoles
- Aprovechar velocidad para ataques rápidos
- Evitar combates de asedio prolongados
- Usar Mangudai para hostigar

### Sumeria
- Enfocarse en economía temprana
- Construir rápido para expandirse
- Usar agricultura mejorada

### Romanos
- Construir defensas fuertes
- Usar Legionarios en formación
- Aprovechar bonus de piedra inicial

### Vikingos
- Rush temprano con Berserkers
- Aprovechar velocidad de recolección
- Combinar ataques y economía

### Incas
- Aprovechar la piedra inicial para asegurar posiciones
- Movilidad rápida gracias a Qhapaq Ñan
- Fuertes unidades cuerpo a cuerpo tempranas

### Chinos
- Fuerte impulso inicial por los recursos extra
- Chu Ko Nu son devastadores en masa
- Edificios con gran supervivencia

### Otomanos
- Gran poder en ataque a distancia a finales del juego
- Jenízaros ofrecen un enorme potencial de daño
- Buena expansión y supervivencia con Sipahis
