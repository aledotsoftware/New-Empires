# 📦 Assets - New Empires

Esta carpeta contiene todos los recursos del juego.

## 📁 Estructura

```
assets/
├── icons/                  # Iconos de unidades y edificios (PNG)
│   ├── villager.png
│   ├── warrior.png
│   ├── archer.png
│   ├── townCenter.png
│   └── ...
│
├── sound/                  # Efectos de sonido (WAV)
│   ├── selectVillager.wav
│   ├── constructionComplete.wav
│   └── ...
│
├── civilization/           # Datos de civilizaciones (JSON)
│   ├── mongols.json
│   ├── sumeria.json
│   ├── romans.json
│   ├── vikings.json
│   └── argentinians.json
│
└── technologies/           # Datos base del juego (JSON)
    ├── base_technologies.json
    ├── base_buildings.json
    └── base_units.json
```

## 📝 Documentación

Para información detallada sobre la estructura de los archivos JSON, ver:
- [JSON_STRUCTURE.md](../docs/sistemas/JSON_STRUCTURE.md)

## 🎨 Formatos

| Tipo | Formato | Uso |
|------|---------|-----|
| Iconos | PNG | Unidades y edificios |
| Sonidos | WAV | Efectos de audio |
| Datos | JSON | Configuración del juego |
